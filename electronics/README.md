# Electronics II — seven lab reports

Electrical Engineering coursework at UNSE in 2025, completed under course supervision. Each project README summarizes the problem, method and results; the original Spanish report is in its `es/` folder. Six folders also contain an English `report.pdf`. The single-stage BJT amplifier currently has no English PDF in this repository.

| Lab | Work | Summary |
| --- | --- | --- |
| TP1 | Half-wave rectifier, capacitor filtering and load-rating checks | [Read](half-wave-rectifier/README.md) |
| TP2 | Diode voltage doubler and quintuplicator under load | [Read](diode-voltage-doubler-and-quintuplicator/README.md) |
| TP3 | Asymmetric Zener clipper and load effects | [Read](zener-diode-clipper/README.md) |
| TP4 | Calculated BJT operating points for three bias networks | [Read](transistor-q-point-quiescent-test/README.md) |
| TP5 | Single-stage common-emitter amplifier designs and frequency sweeps | [Read](bjt-amplifier/README.md) |
| TP6 | Designed and simulated two cascaded common-emitter stages | [Read](cascaded-amplifier/README.md) |
| TP7 | Non-inverting op-amp amplifier and relaxation oscillator | [Read](operational-amplifier/README.md) |

The work covers circuit design, component-rating checks, biasing, gain and bandwidth, oscilloscope measurements and comparison of calculations with observed or simulated behavior. Availability of photos, data and code varies by lab; use each folder's file list rather than assuming every lab contains them.
