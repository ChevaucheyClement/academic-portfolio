# Damp steam and Rankine cycle — supervised coursework

[Original submitted TP (Spanish, PDF)](../../docs/assets/reports/machines/tp1-vapor-humedo-rankine.pdf) · [Portfolio](https://chevaucheyclement.github.io/academic-portfolio/#projects)

This ten-page report bears Clément Chevauchey's name and was submitted for Máquinas Motrices (external combustion) at Universidad Nacional de Santiago del Estero in May 2025 under Ing. Gabriel Miguel. It is a classroom analysis, not a plant study or equipment test.

The report uses steam-property tables to identify thermodynamic states and analyze an ideal Rankine cycle. It then compares an ideal case with specified non-ideal pump, turbine and boiler efficiencies, a higher-pressure case, and a superheated-steam case. It includes state tables, efficiency and specific-work calculations, comparison with a Carnot limit, and figures.

The non-ideal efficiencies are exercise assumptions, not measured plant performance. The higher-pressure case also changes the boiler temperature from 200 °C to 300 °C, so its efficiency difference cannot be attributed to pressure alone.

The PDF is the evidence for this entry. No separate calculation script is published here, and this summary does not claim an independently reproducible software model.
